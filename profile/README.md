## About

XiriGo is a multi-vendor e-commerce platform built for the Maltese market. We provide a unified marketplace where vendors can manage their storefronts and buyers can discover products — all powered by a modern, enterprise-grade tech stack.

## Platform

| Component | Description |
|-----------|-------------|
| **Backend API** | Headless commerce engine with multi-vendor support, AI-powered search, and loyalty system |
| **Vendor Panel** | Full-featured dashboard for vendors to manage products, orders, and analytics |
| **Mobile App** | Native Android & iOS buyer experience |
| **Admin Panel** | Platform-wide management and operations |

## Tech Stack

`TypeScript` · `Next.js` · `React` · `Node.js` · `PostgreSQL` · `Redis` · `Kotlin` · `Swift` · `Docker` · `Kubernetes`
